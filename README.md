# Zeus + Poseidon 非官方繁體中文化補丁

AI 輔助翻譯的免費、部分繁體中文化補丁，適用於已核對的 Steam 英文版。

## 下載

請前往 [Releases](https://github.com/TunaCharlex/zeus-poseidon-fan-translation-zh-tw/releases)，下載附加檔案 `Zeus-ZH-0.1.0-rc9-steam-Clean.zip`。若尚未列出，表示發布檔案仍待上傳。GitHub 自動提供的 Source code 壓縮檔不是可安裝補丁。

## 相容性與完成範圍

- 第一版部分繁中測試補丁，版本識別為 `0.1.0-rc9-steam`。
- 適用於已核對的 Steam 英文執行檔與文字／字型資源；安裝工具會檢查 SHA-256，不接受未知版本。
- 本補丁不另外限制解析度；作者回報目前測試的遊戲內解析度可正常使用，尚未全面驗證第三方解析度修改工具。
- 已完成多項介面、提示文字、事件與部分冒險故事翻譯；修正中文字形對齊、日期重疊及指定故事的標點與分段。
- 部分介面、動態訊息及故事仍是英文，舊譯文標點尚未全面補齊。
- 已完成離線文字繪圖與安裝／還原檢查；作者回報 Steam 原版及本候選版的啟動、進城、存讀檔測試正常。這不代表所有情境或電腦皆已驗證。

## 安裝

1. 關閉遊戲，先備份遊戲與存檔。
2. 解壓縮，將整個 `Zeus-ZH-0.1.0-rc9-steam` 資料夾放入遊戲根目錄。
3. 確認位置為 `Zeus + Poseidon/Zeus-ZH-0.1.0-rc9-steam/Install.cmd`，上一層應有 `Zeus.exe`。
4. 執行 `Check.cmd`，通過後執行 `Install.cmd`，完成後再啟動遊戲。若存取被拒，可用系統管理員身分執行。

不需要 Python，也不需要另外安裝中文字型。補丁只處理四個指定檔案，不修改存檔或設定。

## 還原與更新

關閉遊戲後執行本版本的 `Restore.cmd`，即可還原安裝前的 Steam 英文檔案。

請保留遊戲根目錄的 `Zeus-ZH-Backup-Steam-0.1` 原始備份。缺少或損壞時工具會停止，不能把已漢化的檔案當成原始備份。

先前 rc1–rc8 的解析度修改版不支援直接升級到此 Steam 版；請先完整備份，再用 Steam 驗證檔案恢復原版。後續更新請依各版發布說明操作。
